📘 Phụ Lục: Sử Dụng AI Trong Dự Án

Trang web này được phát triển với sự hỗ trợ từ các công cụ AI để nâng cao hiệu quả và sáng tạo. Dưới đây là thông tin minh bạch về cách sử dụng AI, các prompt chính, cam kết liêm chính học thuật, kiểm chứng thông tin, và nguyên tắc sử dụng AI có trách nhiệm.

🧭 Các Lĩnh Vực Sử Dụng AI

🌐 Gợi Ý Cấu Trúc Website

AI giúp xây dựng khung website với 5 trang chính: cấu trúc tư duy, timeline, biểu đồ Chart.js, popup. Đảm bảo responsive.

Công cụ: v0 (Vercel)

💻 Hỗ Trợ Viết Code

AI cung cấp code mẫu HTML/CSS/JS cho các phần tương tác như timeline, modal popup, tối ưu responsive.

Công cụ: Grok (xAI)

🧩 Tổng Hợp Nội Dung

AI hỗ trợ tổng hợp nội dung học thuật, biên soạn súc tích, đúng nguồn chính thống.

Công cụ: Grok, Google

🔎 Hỗ Trợ Tìm Kiếm Ngữ Nghĩa

AI giúp tìm kiếm thông tin chính xác từ nguồn uy tín, đảm bảo kiểm chứng.

Công cụ: Grok

🧠 Các Prompt Chính Đã Sử Dụng

Với Grok (xAI)

  • "Tạo code cấu trúc website Lịch sử Đảng Cộng sản Việt Nam với timeline, mindmap."
  • "Gợi ý tối ưu code Next.js cho dự án giáo dục."

Với ChatGPT (OpenAI)

  • "Gợi ý code HTML/CSS cho timeline tương tác về Lịch sử Đảng Cộng sản Việt Nam."
  • "Viết nội dung tóm tắt Lịch sử Đảng Cộng sản Việt Nam từ nguồn chính thống."

Với Claude (Anthropic)

  • "Tạo code modal popup responsive cho web giáo dục."
  • "Tổng hợp thông tin từ tài liệu chính thức."
